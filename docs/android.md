# Android build

Generated by `npx cap add android`. It is gitignored — regenerate it rather than
committing it, so the Gradle version never has to be merged by hand.

## Prerequisites

1. **Node 20+**
2. **JDK 17** — `java -version` should report 17. Set `JAVA_HOME`.
3. **Android Studio** (recommended) or the standalone **Android SDK**:
   - Android SDK Platform 34
   - Android SDK Build-Tools 34.0.0
   - Android SDK Platform-Tools (for `adb`)
   - `ANDROID_HOME` pointing at the SDK, and `sdk\cmdline-tools\latest\bin` on `PATH`.

## Build an APK

```bash
npm run android:sync     # builds dist/ and copies it into android/
npm run android:apk      # debug APK → android/app/build/outputs/apk/debug/
```

The APK lands at `android/app/build/outputs/apk/debug/app-debug.apk`. Install it
with `adb install -r <path>` or by copying it to the phone and tapping it (you
will need to allow installs from unknown sources once).

## Release build

The bundled debug APK is unsigned-for-release. For a signed build:

```bash
keytool -genkey -v -keystore fpv-lab.keystore -alias fpvlab \
        -keyalg RSA -keysize 2048 -validity 10000
cd android && ./gradlew assembleRelease
```

Configure the keystore in `android/app/build.gradle` under `signingConfigs`, or
use `~/.gradle/gradle.properties`. Never commit the keystore.

## Notes specific to this app

- **WebGL2** is required. The Capacitor base config enables hardware
  acceleration, but some low-end devices fall back to software rendering; the app
  detects the device tier in `src/render/scene.ts` and drops the pixel ratio and
  shadow map accordingly.
- **Web Serial** (`navigator.serial`) is what the ELRS radio driver uses. It is
  available in the Android WebView only from a secure origin and is not
  implemented in every WebView version. The Controls panel detects this and says
  "Web Serial unavailable" rather than failing silently. Use a gamepad over
  Bluetooth/USB-OTG or the on-screen gimbals on Android.
- **Orientation**: works in both, but landscape is the better flying experience.
  The layout reflows and the gimbals reposition on rotation.
- The back button is handled by the OS, which exits the app — there is no
  in-app back navigation to consume.
